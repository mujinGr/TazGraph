\hypertarget{fileFormats_dotFormat}{}\doxysubsection{\texorpdfstring{.\+dot (\+Graphviz DOT)}{.dot (Graphviz DOT)}}\label{fileFormats_dotFormat}
The DOT format is widely supported by visualization tools such as Graphviz. ~\newline
 It allows advanced layout options, clusters, and styling.

{\bfseries{Structure}}
\begin{DoxyItemize}
\item {\ttfamily digraph G \{ ... \}} defines a directed graph.
\item {\ttfamily node \mbox{[}shape=...\mbox{]}} defines default node attributes.
\item {\ttfamily subgraph cluster\+\_\+X \{ ... \}} allows grouping of nodes into clusters.
\item Edges are defined with {\ttfamily -\/\texorpdfstring{$>$}{>}}.
\end{DoxyItemize}

\hypertarget{fileFormats_pyFormat}{}\doxysubsection{\texorpdfstring{.\+py (\+Python Dictionary Format)}{.py (Python Dictionary Format)}}\label{fileFormats_pyFormat}
The {\ttfamily .py} format represents the graph as a nested Python dictionary. ~\newline
 It contains metadata, nodes (with attributes), and edges (with attributes). ~\newline
 This makes it both human-\/readable and directly usable in Python workflows.

{\bfseries{Structure}}
\begin{DoxyItemize}
\item Top-\/level key\+: {\ttfamily "{}graph"{}}.
\item {\ttfamily directed}\+: whether the graph is directed.
\item {\ttfamily metadata}\+: arbitrary global metadata.
\item {\ttfamily nodes}\+: dictionary of nodes keyed by ID, each with\+:
\begin{DoxyItemize}
\item {\ttfamily label}\+: display label.
\item {\ttfamily metadata}\+: dictionary of attributes (hover text, size, colors, etc.).
\item {\ttfamily x}, {\ttfamily y}\+: position coordinates.
\end{DoxyItemize}
\item {\ttfamily edges}\+: list of edges, each with\+:
\begin{DoxyItemize}
\item {\ttfamily source}, {\ttfamily target}\+: node IDs.
\item {\ttfamily label}\+: edge label.
\item {\ttfamily metadata}\+: dictionary of edge attributes (id, size, etc.).
\end{DoxyItemize}
\end{DoxyItemize}

\hypertarget{fileFormats_graphmlFormat}{}\doxysubsection{\texorpdfstring{.\+graphml (\+Graph\+ML XML Format)}{.graphml (GraphML XML Format)}}\label{fileFormats_graphmlFormat}
Graph\+ML is an XML-\/based format standardized for graph representation. ~\newline
 It is supported by many external tools (Gephi, y\+Ed, NetworkX, etc.). ~\newline
 \doxylink{classNode}{Node} and edge attributes are defined using {\ttfamily \texorpdfstring{$<$}{<}key\texorpdfstring{$>$}{>}} and {\ttfamily \texorpdfstring{$<$}{<}data\texorpdfstring{$>$}{>}} elements.

{\bfseries{Structure}}
\begin{DoxyItemize}
\item Root element {\ttfamily \texorpdfstring{$<$}{<}graphml\texorpdfstring{$>$}{>}}.
\item {\ttfamily \texorpdfstring{$<$}{<}key\texorpdfstring{$>$}{>}} definitions specify attributes (e.\+g., x, y for node positions).
\item {\ttfamily \texorpdfstring{$<$}{<}graph\texorpdfstring{$>$}{>}} contains {\ttfamily \texorpdfstring{$<$}{<}node\texorpdfstring{$>$}{>}} and {\ttfamily \texorpdfstring{$<$}{<}edge\texorpdfstring{$>$}{>}} elements.
\item Each {\ttfamily \texorpdfstring{$<$}{<}node\texorpdfstring{$>$}{>}} has an {\ttfamily id} and {\ttfamily \texorpdfstring{$<$}{<}data\texorpdfstring{$>$}{>}} for attributes.
\item Each {\ttfamily \texorpdfstring{$<$}{<}edge\texorpdfstring{$>$}{>}} has an {\ttfamily id}, {\ttfamily source}, and {\ttfamily target}.
\end{DoxyItemize}
