\doxysubsection{Detailed Description}
Architecture and workflow for loading maps and paths. 

The map loading system separates file parsing from entity creation. Each parser derives from \doxylink{classIMapParser}{IMap\+Parser} and interacts with Map.\+cpp via callbacks.
