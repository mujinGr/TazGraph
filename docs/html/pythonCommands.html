#Save/Load Python state Using python, we can also save the state of envirnoment in .pkl format by executing:

import pickle
def my_object():
return 4;
with open("state.pkl", "wb") as f:
pickle.dump(my_object, f)

To load, do:

with open("state.pkl", "rb") as f:
my_object = pickle.load(f)
print(my_object());
